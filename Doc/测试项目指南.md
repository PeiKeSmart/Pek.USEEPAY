# 测试项目快速指南

## 概述

为了方便 UseePay 组件的本地调试，我们从 [Pek.Zero](https://github.com/PeiKeSmart/Pek.Zero) 仓库提取了 MVC 项目作为测试环境。

## 测试项目位置

```
Pek.USEEPAY/
├── Pek.USEEPAY/              # UseePay 组件源码
├── Pek.USEEPAY.Samples/     # 测试项目
│   ├── Controllers/
│   │   └── UseePayTestController.cs
│   ├── Views/
│   │   └── UseePayTest/
│   ├── README.md
│   └── Pek.USEEPAY.Samples.csproj
└── Doc/
    ├── 配置说明.md
    └── 测试项目指南.md    # 本文档
```

## 快速启动

### 方式一：命令行

```bash
cd Pek.USEEPAY.Samples
dotnet run
```

### 方式二：Visual Studio

1. 打开解决方案 `Pek.USEEPAY.slnx`
2. 右键 `Pek.USEEPAY.Samples` 项目 → 设为启动项目
3. 按 F5 运行

### 方式三：VS Code

1. 打开 `Pek.USEEPAY.Samples` 目录
2. 按 F5 或使用命令 `.NET: Run`

## 访问测试页面

启动后访问：`http://localhost:5000/UseePayTest/Index`

测试页面提供：
- 配置信息展示
- 支付订单创建测试
- 支付回调测试
- 支付返回页面

## 配置步骤

### 1. 首次运行生成配置

首次运行时会在 `Pek.USEEPAY.Samples` 目录下生成 `UseePay.config` 文件。

### 2. 修改配置

编辑 `UseePay.config`，填入从 UseePay 商户系统获取的参数：

```xml
<UseePay>
  <Enable>true</Enable>
  <UseSandbox>true</UseSandbox>
  <SandboxMerchantId>你的沙箱商户号</SandboxMerchantId>
  <SandboxKey>你的沙箱密钥</SandboxKey>
  <SandboxAppId>你的网站域名</SandboxAppId>
  <!-- ... 其他配置 -->
</UseePay>
```

### 3. 重启应用

修改配置后重启应用使配置生效。

## 测试流程

### 完整支付流程测试

1. **配置环境**：修改 `UseePay.config`
2. **创建订单**：调用创建订单接口
3. **发起支付**：跳转到 UseePay 支付页面
4. **支付完成**：UseePay 回调 Notify 接口
5. **页面返回**：跳转到 Return 页面

## 常见问题

### Q: 配置文件没有生成？
**A**: 确保应用程序对目录有写入权限，或手动创建 `UseePay.config` 文件。

### Q: 配置修改后不生效？
**A**: 需要重启应用程序，NewLife 配置框架会在启动时加载配置。

### Q: 测试页面显示"未配置"？
**A**: 检查 `UseePay.config` 文件是否存在且格式正确，确保对应环境的参数已填写。

### Q: 如何切换到生产环境？
**A**: 在 `UseePay.config` 中将 `<UseSandbox>true</UseSandbox>` 改为 `false`。

## 注意事项

1. **不要提交敏感信息**：将 `UseePay.config` 添加到 `.gitignore`
2. **使用沙箱环境测试**：正式上线前务必在沙箱环境充分测试
3. **签名验证**：所有回调必须验证签名
4. **错误处理**：添加完善的错误处理和日志记录
