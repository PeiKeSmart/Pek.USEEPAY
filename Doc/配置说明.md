# UseePay 配置说明

## 概述

UseePay 支付组件提供了完整的沙箱（Sandbox）和生产（Prod）环境配置，两个环境相互独立，需要分别配置。

## 环境说明

### Sandbox 沙箱环境
- **API 网关**：https://pay-gateway1.uat.useepay.com/
- **商户系统**：https://mc1.uat.useepay.com/
- **特点**：用于开发测试，无 IP 白名单限制

### Prod 生产环境
- **API 网关**：https://pay-gateway.useepay.com/
- **特点**：正式交易环境，需要 IP 白名单

## 配置参数

### 基础配置

| 参数 | 类型 | 说明 |
|-----|------|------|
| `Enable` | Boolean | 是否启用 UseePay 支付 |
| `UseSandbox` | Boolean | 是否使用沙箱环境，默认 false |

### Sandbox 沙箱环境配置

| 参数 | 类型 | 说明 |
|-----|------|------|
| `SandboxApiUrl` | String | API 网关地址，默认：https://pay-gateway1.uat.useepay.com/ |
| `SandboxMerchantUrl` | String | 商户系统地址，默认：https://mc1.uat.useepay.com/ |
| `SandboxMerchantId` | String | 商户号（从商户系统获取） |
| `SandboxKey` | String | 密钥（MD5 密钥或 RSA 私钥） |
| `SandboxAppId` | String | 网站域名（不带 http:// 或 https://） |
| `SandboxSignType` | String | 签名类型（MD5 或 RSA），默认 MD5 |

### Prod 生产环境配置

| 参数 | 类型 | 说明 |
|-----|------|------|
| `ProdApiUrl` | String | API 网关地址，默认：https://pay-gateway.useepay.com/ |
| `ProdMerchantId` | String | 商户号（从商户系统获取） |
| `ProdKey` | String | 密钥（MD5 密钥或 RSA 私钥） |
| `ProdAppId` | String | 网站域名（不带 http:// 或 https://） |
| `ProdSignType` | String | 签名类型（MD5 或 RSA），默认 MD5 |

### 通用配置

| 参数 | 类型 | 说明 |
|-----|------|------|
| `NotifyUrl` | String | 支付结果异步通知地址 |
| `ReturnUrl` | String | 支付完成同步返回地址 |

## 配置示例

### appsettings.json 配置

```json
{
  "UseePay": {
    "Enable": true,
    "UseSandbox": true,
    "SandboxMerchantId": "your_sandbox_merchant_id",
    "SandboxKey": "your_sandbox_key",
    "SandboxAppId": "www.example.com",
    "SandboxSignType": "MD5",
    "ProdMerchantId": "your_prod_merchant_id",
    "ProdKey": "your_prod_key",
    "ProdAppId": "www.example.com",
    "ProdSignType": "MD5",
    "NotifyUrl": "https://www.example.com/api/payment/notify",
    "ReturnUrl": "https://www.example.com/payment/result"
  }
}
```

## 使用方法

### 获取配置

```csharp
// 获取配置实例
var setting = UseePaySetting.Current;

// 检查是否启用
if (!setting.Enable)
{
    throw new InvalidOperationException("UseePay 未启用");
}

// 获取当前环境的配置
var apiUrl = setting.GetApiUrl();           // 根据 UseSandbox 返回对应的 API 地址
var merchantId = setting.GetMerchantId();   // 根据 UseSandbox 返回对应的商户号
var key = setting.GetKey();                 // 根据 UseSandbox 返回对应的密钥
var appId = setting.GetAppId();             // 根据 UseSandbox 返回对应的 AppId
var signType = setting.GetSignType();       // 根据 UseSandbox 返回对应的签名类型
```

### 辅助方法

配置类提供了便捷的辅助方法，根据 `UseSandbox` 属性自动返回对应环境的配置：

- `GetApiUrl()` - 获取当前使用的 API 网关地址
- `GetMerchantId()` - 获取当前使用的商户号
- `GetKey()` - 获取当前使用的密钥
- `GetAppId()` - 获取当前使用的 AppId
- `GetSignType()` - 获取当前使用的签名类型

## 对接步骤

### 1. 激活 Sandbox 环境
提供 email 邮箱给 UseePay 运营，随后会收到激活邮件进行账户激活。

### 2. 获取商户号和密钥
登录 [Sandbox 商户系统](https://mc1.uat.useepay.com/)，在密钥管理中获取商户号和密钥（MD5 或 RSA）。

### 3. 提交网站 AppId
在商户系统的网站管理中提交网站域名作为 AppId（不要带 https:// 或 http://）。

### 4. 配置参数
将获取的商户号、密钥、AppId 配置到 `UseePaySetting` 中。

### 5. 集成 API 接口
根据业务需求集成 UseePay 提供的 API 接口。

### 6. 测试完成
在 Sandbox 环境进行完整的流程测试。

### 7. 激活生产环境
测试通过后，向 UseePay 申请激活生产环境，获取生产环境的商户号和密钥。

### 8. 切换到生产环境
将 `UseSandbox` 设置为 `false`，开始正式交易。

## 注意事项

1. **环境独立**：Sandbox 和 Prod 环境相互独立，商户号、密钥等信息不能混用
2. **AppId 格式**：网站域名不要带 `https://` 或 `http://`，需要与商户系统提交的网站完全匹配
3. **IP 白名单**：生产环境有 IP 白名单限制，请勿使用客户端直接请求 UseePay 服务器
4. **签名方式**：支持 MD5 和 RSA 两种签名方式，根据实际申请的密钥类型选择
5. **环境切换**：先在 Sandbox 环境完成测试，确认无误后再切换到生产环境
